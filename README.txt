Requisitos previos

- Node.js 18 o superior
- npm

Instalación

1. Clonar el repositorio y moverse a la rama `hw-02`:


   git clone https://github.com/JaimeHO2006/Arquitectura_de_sistemas.git
   cd Arquitectura_de_sistemas
   git checkout hw-02


2. Instalar las dependencias:
   npm install


Ejecución

npx tsc
node dist/index.js


Si todo salió bien, verás en la consola:

Servidor corriendo en http://localhost:3000/docs/
